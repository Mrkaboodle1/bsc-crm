## Source confidence

- 🟢 Government, peer-reviewed, AIHW/ABS = highest trust.
- 🟡 Industry survey (Allianz, Triple P, Mi3) = high but vendor-funded; check methodology if a number is decision-critical.
- 🟠 Trade press (TheDrum, ALM, Adligator) = directionally useful; treat tactical claims as hypotheses, not facts.

Every cited claim has its source URL inline.
